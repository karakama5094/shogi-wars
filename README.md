# shogi-wars — CPU対戦専用

9×9将棋盤、持駒、成り選択、効果音、演出、棋譜一覧を備えた静的Webアプリです。
オンライン対戦・マッチング・対人レーティング・チャット・対戦サーバーは開発対象外です。

## 起動

リポジトリ全体を静的サーバーで配信してください。ビルドや依存パッケージのインストールは不要です。

```sh
python3 -m http.server 8000
```

`http://localhost:8000` を開きます。盤面デザインには既存のTailwind CDN、Font Awesome、Google Fontsを使用しています。
`index.html` だけではなく `src/domain/rules.js` も配信する必要があります。

## テスト

Node.js 20以上で実行します。追加依存はありません。

```sh
npm test
```

ルール層を直接読み、ブラウザで使用する対局クラスをVMで実行するテストです。
駒の移動、二歩、強制成り、王手回避、打ち歩詰め、玉取りの拒否、千日手・連続王手、
終局後の着手拒否、CPUコールバックのキャンセル、待った、設定の確定、経過時間を検証します。
固定seedの160手の合法手列では駒数保存と局面復元も検証します。
実ブラウザの描画・タッチ・音声・バックグラウンド挙動を保証するテストではありません。

## 構成

- `src/domain/rules.js`: DOM・音声・タイマーに依存しないルール、初期局面、反復判定。
- `index.html`: 既存画面、CPU選択、対局進行、時計、音声、演出。
- `tests/`: Node.jsによるルール・対局状態の回帰テスト。

着手確定時に合法性と成りを再検証します。反復局面は盤面・持駒・手番で識別し、
4回目で千日手にします。その期間の同一側の全着手が王手なら、その側の反則負けです。
新対局・待った・終局・着手確定では予約処理を無効化し、キャンセル前に配送されたコールバックも世代番号で拒否します。
時計は単調増加時刻の差分で計算します。バックグラウンドでも消費する方針で、
次の時計更新または着手確定時に経過時間を反映します。待ったでは保存した残り時間を復元します。

差のない難易度選択、根拠のないRate・段級位・達成率、オフライン2人対局、棋神ボタンを非表示または除去しました。

この段階でPhase 1全体の合格やiPhone実機での動作保証とはしません。

## 本格AI対局・棋神

`engine-lab/play.html` では、やねうら王による名人（10秒）・プロ（5秒）・アマ（1秒）のCPU対局を利用できます。
棋神降臨による1手代指しと、終局後の全局面解析に利用回数の制限はありません。
形勢は先手＋・後手−の−100〜＋100、分布バーと推移グラフで表示します（勝率・実在の段級位ではありません）。
詳細は [CPUレベル・棋神の仕様](docs/cpu-levels-kishin.md) を参照してください。
