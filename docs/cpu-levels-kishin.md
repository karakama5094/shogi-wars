# CPU 3段階・棋神降臨・棋神解析・形勢分布

対象ページ: `/engine-lab/play.html`（通常ページの「AI対局」リンクから移動）。

## CPUレベル

新対局設定で、名人=10秒、プロ=5秒、アマ=1秒を選択する。既定値はプロ。
選択は「対局開始」で反映し、進行中の局面や時計には即時反映しない。
全レベルとも同じやねうら王でSkillLevel=20、DepthLimit=0、NodesLimit=0。
違いは1手の探索時間上限だけで、実在の名人・プロ・アマの棋力認定ではない。
「最善手」は指定時間内のエンジン推奨手であり、理論的な最善の保証ではない。
持ち時間不足時は、150msの余裕を見て探索上限を短縮する。

## 棋神降臨（無限）

自分の手番にボタンを押すと、最大10秒の探索で1手を代指しする。
自動指し後は選択したレベルのCPUへ手番を渡す。利用回数の制限はない。
代指しの思考時間は人間側の持ち時間に含む。
思考中は盤面操作を止め、二重押し・成り選択との競合を防ぐ。
待った・新対局・一時停止・投了・時間切れで無効化し、遅れた結果は適用しない。
投了推奨の場合は人間を自動投了させず、推奨を表示する。

## 形勢分布と推移グラフ

USIのscoreは手番側基準なので、先手を正、後手を負へ変換する。
通常評価は `round(100 * tanh(先手基準cp / 600))` を−99〜＋99に制限する。
詰み評価は先手勝ち＋100、後手勝ち−100。mate 0は手番側の敗勢として扱う。
未評価・欠損は「未評価」とし、勝手に0（互角）を補わない。

表示ラベルは絶対値10未満=互角、30未満=やや有利、70未満=優勢、それ以上=勝勢。
棒の配分は先手 `(100+表示値)/2`、後手は残り。これは形勢を見やすくする目安で、勝率・Elo・段級位ではない。
各評価に局面の手数を付ける。CPU思考中と棋神降臨で得られた根局面の評価を表示し、
常に着手後の最新局面を解析済みと見せない。待ったや分岐で一致しない局面の評価は除去する。
対局後解析では全局面の点を描き、点や結果行の選択で過去の盤面を閲覧できる。
閲覧用の派生オブジェクトで描画し、対局本体の盤面・持駒・棋譜・勝敗は変更しない。

## 棋神解析（無限）

終局すると解析パネルを表示する。初期局面と各着手後の全局面を順に解析する。
解析時間は1局面あたり1秒・5秒・10秒（既定1秒）。何度でも再実行できる。
各局面の推奨手・生の評価・−100〜＋100表示・深さ・読み筋を取得する。
推奨手を合法性検証し、棋譜を再生しながら不変の閲覧用スナップショットを保存する。
最終局面が合法手なしの場合は手番側敗勢として表示し、不可能な着手を強制しない。

処理中は進捗を表示し、任意停止できる。通信エラー・新対局・画面非表示・ページ離脱で中断し、古い結果を新しい対局に混ぜない。
全局面を毎回ローカル解析するため、概ね「局面数×選択秒数」の処理時間が必要。
途中結果も閲覧・コピーでき、コピーには実際に選択した解析時間・棋譜・各局面の結果を記録する。
途中で停止した結果を全局面完了と表示しない。データは自動送信しない。
